# Week 1: Python Basics — Personal Introduction Program

A beginner-friendly Python program that asks the user questions and prints a personalized welcome message.

## Requirements
- Python 3.10 or newer recommended
- No third-party packages required

## Project structure
```text
personal-introduction/
├── personal_intro.py
├── README.md
├── requirements.txt
└── screenshot.png  (add your own screenshot before submitting)
```

## Run the program
1. Install Python from https://www.python.org/downloads/
2. Open this folder in VS Code or a terminal.
3. Run `python personal_intro.py`.
4. On some Windows installations, use `py personal_intro.py`.
5. Answer the questions in the terminal.

## Example output
```text
What is your name? Alex
How old are you? 21
What is your favorite hobby? Coding
Which city do you live in? Pune
What is your favorite food? Pizza

🎉 Welcome, Alex! 🎉
You are 21 years old and enjoy Coding.
You live in Pune, and your favorite food is Pizza.
Thanks for introducing yourself. Have a great day!
```

## Concepts practiced
- `input()` and `print()`
- Variables, strings, and f-strings
- Integer conversion and basic error handling
- Functions, comments, and conditional statements
